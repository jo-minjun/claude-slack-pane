# Slack 패널 mod 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code 오른쪽 패널에서 Slack 채널·스레드를 읽고, 메시지와 사진을 보내고, 메시지·스레드를 프롬프트에 인용하는 mod `claude-slack-mod`를 만든다.

**Architecture:** hooks 모듈(`hooks/register.tsx`)은 hook 연결만 하고, 기능은 `src/` 아래 작은 모듈로 나눈다. Slack 호출은 `SlackClient` 인터페이스 뒤에 두고, 구현체는 `$.mcp.call`로 연결된 Slack MCP를 부르며 MCP 텍스트 출력은 `parse.ts`에서만 해석한다. 화면 상태는 `$.state` atom에 두고, 새로고침은 `$.clock.after` 체인으로 열린 뷰 하나만 조회한다.

**Tech Stack:** Claude Code mod API 2.1.316(`claude-code`, `claude-code/testing`), TypeScript + JSX(`h`), `claude plugin validate`, `claude plugin test`, `tsc`.

**Spec:** `docs/superpowers/specs/2026-11-02-slack-mod-design.md`

## Global Constraints

- 플러그인 이름은 `claude-slack-mod`다. `$.state` 참조의 `plugin`도 `claude-slack-mod`다. 패널 id는 `slack`이다.
- mod가 그리는 모든 글자(버튼, 안내, 오류, 명령 출력, 토스트)는 영어다.
- 모듈과 모듈이 import하는 파일은 `.ts`/`.tsx`다. `import()`와 Node API를 쓰지 않는다. 외부 접근은 `$`로만 한다.
- 테스트 환경에는 fs, network, process가 없다. fixture는 `.txt`가 아니라 문자열을 export하는 `test/fixtures/*.ts`다.
- fixture의 메시지 본문, 이름, 이메일, 전화번호, 채널 ID는 모두 가짜 값이다. 실제 회사 정보(워크스페이스 도메인, 실제 채널 ID, 실제 사람 이름)를 저장소에 넣지 않는다.
- 설정값은 `mcpServer`(string, 기본값 `plugin:slack:slack`) 하나다.
- `$.store` 키는 `refreshSeconds`(기본값 10), `workspaceDomain`, `myUserId` 세 개다.
- 새로고침 주기 범위는 5–300초 정수다.
- 조회는 모두 `response_format: "detailed"`다.
- 상수: 채널 목록 `limit` 200, 검색 `limit` 20, 메시지 페이지 50, 과거 위치 앞뒤 25, 인용 최대 메시지 200개·40,000자, 사진 확장자 `png jpg jpeg gif webp`.
- 프로필 응답에서는 `User ID`만 꺼내고, 나머지는 저장하거나 로그로 남기지 않는다.
- 테스트 기대값은 프로덕션 상수를 import하지 않고 리터럴로 쓴다.
- 커밋 메시지는 한국어 `<type>: <subject>` 형식이고, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙인다.

## Review Focus

1. 메시지 본문에 `Thread: 3 replies`처럼 메타 줄과 같은 모양의 줄이 들어 있어도, 파서는 본문을 자르지 않고 마지막 메타 줄만 메타로 읽어야 한다. → Task 2 `parseChannelMessages keeps meta-like body lines` 테스트.
2. 메시지가 없는 채널, 결과가 없는 검색은 `ParseError`가 아니라 빈 목록이어야 한다. → Task 2 `empty channel` / `empty search` 테스트.
3. 본문의 HTML 엔티티(`&amp;`, `&lt;`, `&gt;`)와 Slack 링크 표기(`<url|label>`)는 화면과 인용 원문에서 사람이 읽는 형태여야 한다. → Task 2 `decodeSlackText` 테스트.
4. 사용자가 인용 표시를 손으로 고쳐 ID가 틀리거나 원문을 찾을 수 없어도, 프롬프트는 전송되고 실패가 `context`에 적혀야 한다. → Task 4 `failed fetch adds unavailable note` 테스트.
5. 첨부 경로가 없거나, 확장자가 이미지가 아니거나, 경로에 공백·`~`가 있어도 업로드 URL을 받기 전에 명확한 오류로 끝나야 한다. → Task 9 `prepareFile` 테스트.

## 공유 타입 (`types/index.d.ts`, Task 1에서 작성)

```ts
export type ChannelKind = 'public' | 'private' | 'im' | 'mpim'
export type Channel = { id: string; name: string; kind: ChannelKind }
export type Message = {
  ts: string; userId: string; userName: string; text: string
  replyCount: number; threadTs?: string; hasFile: boolean
}
export type SearchHit = {
  channelId: string; channelName: string; ts: string; threadTs?: string
  userName: string; text: string; permalink: string
}
export type Page<T> = { items: T[]; nextCursor?: string }
export type UploadTicket = { uploadUrl: string; fileId: string }
export type View =
  | { kind: 'channel'; channelId: string; label: string; anchorTs?: string }
  | { kind: 'thread'; channelId: string; label: string; threadTs: string; back: { anchorTs?: string } }
export type Loadable<T> = { items: T[]; cursor?: string; isLoading: boolean; error?: string }
export type LeftState = { mode: 'channels' | 'search'; query: string; filters: string; page: number; results: Loadable<SearchHit> }
export type Attachment = { path: string; name: string; size: number; mime: string; tempDir?: string }
export type ComposerState = { isPathMode: boolean; attachment?: Attachment; isSending: boolean; error?: string }
export type RefreshState = { status: 'idle' | 'refreshing' | 'paused' | 'error'; lastSuccessAt?: number; failedAt?: number }

declare module 'claude-code' {
  interface PluginState {
    'claude-slack-mod': {
      channels: Shaped<Loadable<Channel> & { page: number }>
      left: Shaped<LeftState>
      view: Shaped<View | null>
      messages: Shaped<Loadable<Message>>
      selectedTs: string | null
      composer: Shaped<ComposerState>
      refresh: Shaped<RefreshState>
      intervalSeconds: number
      paneOpen: boolean
      banner: string | null
    }
  }
}
```

`Message.ts`는 Slack ts 문자열(`"1793337289.953239"`)이다. 표시 시각은 `ts`의 정수부(초)로 계산한다.
